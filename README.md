# Fatemeh Rashno — Portfolio

React + Vite, hash routing (works on any static host or from file).

    npm install
    npm run dev      # develop
    npm run build    # output in dist/ — upload this folder to any static host

Routes: #home, #about, #smart-invest, #coupon-creation, #foodpro
